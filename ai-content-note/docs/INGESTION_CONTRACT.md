# Ingestion Contract / 收錄契約

## Hard gates / 硬閘門

- Full article, transcript, specification, paper, or repository evidence is required.
- Search snippets and titles cannot become notes.
- One independent case, experiment, or argument maps to one D card.
- Numeric evidence, dates, quotations, internal names, commands, and parameters are preserved verbatim.
- A note is `completed` only after GitHub readback and Sheet URL replacement succeed.
- A blocked item records a concrete error and processing continues to the next rank.

## Frontmatter / Metadata

Every note must include stable ID, source/canonical URL, publication date, score, category, mapping targets, GitHub path, and legacy Google Doc URL. See [`../schemas/note-frontmatter.schema.md`](../schemas/note-frontmatter.schema.md).

## Category rules / 分類規則

Classification is technical-domain-first, not publisher-first. Source remains metadata. A note may carry multiple categories, but one primary directory is mandatory.

## Content rule / 內容規則

The Markdown body contains only v6.6 cards. No generic executive summary, no M-series dashboard, and no silent compression of N/D/P cards.
