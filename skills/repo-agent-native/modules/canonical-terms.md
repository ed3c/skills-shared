# repo-agent-native canonical terms

| Term | Canonical meaning |
|---|---|
| source-anchored claim | A repository claim whose relevant source body was read at the recorded subject and whose `source_ref` resolves inside that subject. |
| candidate | A location or relation nominated by text, semantic, symbol, graph, generated, or memory retrieval; not yet a fact. |
| negative invariant | A bounded claim that a behavior or assumption is absent, accompanied by searched paths, queries, exclusions, and counterexample sought. |
| broken-box inference | Reasoning from visible callers, callees, shared state, timeout and failure paths while explicitly separating known source facts from inference. |
| OPBE | Optional-Parameter Branch Exhaustion: enumerate each optional input and every branch or routing effect it activates. |
| evidence ceiling | The highest claim class a mechanism may support before additional readback or execution evidence. |
| readback | Directly reading the current source/document/test/receipt nominated by a candidate provider before promotion. |
| subject identity | The repository/subtree plus immutable commit or tree to which evidence and assertions apply. |
| provider observation | A recorded provider identity, health, freshness, scope and returned candidate; never implicit source truth. |
| Human Admit | The declared human authority required for merge, promotion, durable-law changes, provider activation or other irreversible admission. |

Do not silently rename these terms in outputs. A consumer may add domain vocabulary but may not change these meanings.
