# Modules

Modules are trigger-selected task families and provider/domain adapters. They cannot redefine the universal rubric.

| Module | Purpose |
|---|---|
| `ecommerce-dispute-eval-matrix.md` | Human-readable worked mapping |
| `ecommerce-dispute/` | Executable adapter protocol, six cases, deterministic runner |

A domain module may bind universal concepts to local thresholds and tools. It must not promote those thresholds or tools into global Skill procedure law.
