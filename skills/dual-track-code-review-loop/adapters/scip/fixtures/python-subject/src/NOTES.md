# Subject notes

This file is here to be missed.

`scip-python` indexes Python. It does not index Markdown, and a Markdown file
this indexer never opened is indistinguishable downstream from a Python file it
opened and found clean -- unless something writes the difference down. The
adapter declares this blob in the subject denominator and records a matching
omission, which is what forces the coverage ceiling to `PARTIAL_LOWER_BOUND`.

Delete it and the `PARTIAL_COVERAGE_PROMOTED_TO_COMPLETE` control loses the
ground it stands on.
