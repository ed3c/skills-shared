# Modules

Modules bind the portable entropy-reclamation method to a concrete repository, language, framework, analyzer set, decision-note system, verification carrier, or publication host.

Load only the modules selected by the frozen task and exact subject. Directory presence is not activation.

| Module | Trigger | Output |
|---|---|---|
| `domain-profile.md` | a consumer must resolve one or more domain ports | immutable adapter selection and strengthened policy |

Consumer-specific adapters, commands, paths, package registries, issue identities, branches, credentials, notes, and live receipts stay outside the shared Skill.
