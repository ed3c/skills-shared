## Agent roles

### Tech Lead

Owns exact-subject binding, capability and boundary inventory, candidate/root-cause DAG, writer/path/resource leases, one convergence owner, verification plan, global objective, rollback and Local Handoff.

The Tech Lead must not self-certify the global objective or infer absent dynamic/persisted/external consumers from static search alone.

### Independent Shadow Architect

Read-only. Receives the same immutable subject and independently attacks:

```text
complexity relocation rather than removal
missing production/ambiguous/dynamic consumers
hidden source-of-truth duplication
ownership boundary collapse
lost lifecycle or resource-quiescence behavior
weakened trust/accessibility/data-loss protections
old rationale still applying
local PASS hiding global failure
residue or migration glue equal to removed burden
fixture/static evidence promoted to live
```

Shadow outputs findings plus `ELIGIBLE_FOR_IMPLEMENTATION`, `HOLD`, `REJECT`, or `HUMAN_ADMIT_REQUIRED`. Shadow never edits the Builder branch or becomes a second state writer.

A missing prerequisite blocks advancement. `AUDIT_COMPLETE` is valid when no safe cut exists.

## Writer and mutation laws

- One active writer per mutation subject; path/resource leases must be disjoint.
- One cut owns one ownership boundary. Do not mix unrelated cleanup.
- A child branch consumes named unmerged parent bytes/contracts; path-disjoint work stays sibling work.
- Do not weaken tests, public contracts, compatibility checks, trust boundaries, migration guarantees, cleanup, rollback, or evidence requirements to make deletion pass.
- Remove the obsolete obligation end to end; do not hide it behind a wrapper or duplicate derived state elsewhere.
- Domain adapters may only strengthen constraints, add evidence, narrow effects, or reduce authority.

## Verification obligations

For each applied cut preserve exact-subject evidence for:

```text
decisive check
relevant type/lint/unit/integration/build/codegen/smoke gates
residue search for removed symbols/paths/strings/config
dynamic/persisted/compatibility boundary checks when applicable
resource/lifecycle cleanup where applicable
nominating analyzer rerun
global objective
full-diff scope review
rollback subject
```

Failed, blocked, stale, cancelled and rejected candidates remain in the denominator.

## Evidence ceiling

Current shared method implementation can establish contract and deterministic audit evidence. It does not automatically prove a concrete consumer deletion, cross-language live adoption, real Git Town worktree/sync execution, merge, release or production acceptance.

Preserve the states:

```text
PASS
FAIL
ABSENT
NOT_IMPLEMENTED
NOT_EXERCISED
SKIPPED_BY_POLICY
HUMAN_ADMIT_REQUIRED
```

## Completion report

Report target commit/tree, boundaries, all candidates and rejections, selected ownership cut, Shadow findings, changed paths, decisive/broad/residue/global results, conceptual reduction versus replacement burden, failed attempts, cleanup, exact Stack/PR subjects, remaining evidence lanes, rollback and Human-owned operations.
