# Review-handoff domain profile

Historical provider/model/consumer mappings remain recoverable from pre-refactor blob `9ffbe86e6796a1532eedeff2a6ba04971907268d`.

## Trigger
Load when a concrete reviewer model/provider, host carrier, consumer repository, pilot family, or review transport must be selected.

## Non-trigger
Do not load for generic exact-subject review packets, reviewer isolation, evidence anchoring, findings-only output, dissent preservation, or Human Admit handoff.

## Assumptions
Review can operate from an exact public task/artifact/evidence packet without requiring private chain of thought.

## Specialization inventory
Named reviewer/model mappings, consumer paths, family pilots, host review carriers, and repository-specific artifact routes belong here.

## Evidence ceiling
A reviewer verdict is advisory unless the evidence contract admits that judgment class; deterministic safety failures remain vetoes.

## Fallback
If a preferred reviewer is unavailable, use another implementation satisfying the frozen independence contract or return the review lane as unavailable.

## Forbidden overrides
This module may not override `CORE-LAW-001` through `CORE-LAW-005`, suppress valid dissent, request private reasoning, or widen provider/secret/merge authority.
