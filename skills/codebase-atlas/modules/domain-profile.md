# Architecture-atlas rendering profile

Historical renderer/style/browser specifics remain recoverable from pre-refactor blob `c02858043e4aea0fdeb23573a9e71c73b3f5a09a`.

## Trigger
Load when a concrete visual renderer, projection formula, interaction model, viewport/browser test matrix, share-safety profile, or style system must be bound.

## Non-trigger
Do not load for generic repository inventory, evidence-bound architecture modeling, node/edge derivation, projection validation, interaction coverage requirements, or artifact handoff.

## Assumptions
Repository topology and evidence can be represented independently from any one visual style or browser implementation.

## Specialization inventory
Isometric/drafting visual treatment, palette/layout rules, renderer schemas, interaction states, screenshot dimensions, browser automation, and share-safety/export details belong here.

## Evidence ceiling
A rendered atlas or screenshot proves projection behavior only; architecture claims remain bounded by repository source and runtime evidence.

## Fallback
If the selected renderer/browser stack is unavailable, emit a machine-readable architecture graph and projection contract with the rendering lane explicitly unavailable.

## Forbidden overrides
This module may not override `CORE-LAW-001` through `CORE-LAW-005`, change architecture facts to fit a renderer, hide uncovered repository areas, or widen browser/network/secret/merge authority.
